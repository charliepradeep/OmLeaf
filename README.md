# OmLeaf

A calm, offline pranayama timer: guided breathing, a visual breathing circle, and AUM / A / humming chant
tones at a pitch you choose. No account, no ads, no internet permission.

The Android app lives in [`android/`](android/) (see [`android/README.md`](android/README.md) to build it) and the
iPhone and iPad app in [`ios/`](ios/) (see [`ios/README.md`](ios/README.md)).
